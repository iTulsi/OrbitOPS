# Code of Conduct

OrbitOPS welcomes contributors with different experience levels and backgrounds. Participation in the repository must remain respectful, technical, and focused on improving the project.

## Expected behavior

- Discuss ideas and code without attacking the person proposing them.
- Give actionable feedback and explain technical disagreements.
- Respect maintainer decisions about scope, architecture, and project timing.
- Credit other contributors and disclose reused work.
- Protect private information, credentials, and security reports.
- Ask before starting a large change when an issue has not been accepted or assigned.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal insults.
- Spam, fabricated results, plagiarism, or misleading contribution claims.
- Publishing private conversations, credentials, or vulnerability details without permission.
- Repeatedly opening duplicate issues or pull requests after a maintainer has explained the decision.
- Pressuring maintainers or contributors for immediate reviews.

## Reporting and enforcement

Report conduct concerns privately to `tulsitomar2019@gmail.com`. Include links, screenshots, or other relevant context while avoiding unnecessary personal information.

Maintainers may edit or remove content, request changes, issue a warning, temporarily restrict participation, or permanently block participation depending on severity and repetition. Reports will be handled as privately and fairly as practical.
